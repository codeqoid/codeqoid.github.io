A4 Document Corner Detection with A* Search

Team project · Fundamentals of AI · Group 29

Finds the four corners of an A4 sheet in messy real-world photos by treating detection as a search problem.

  • Image pipeline: Difference-of-Gaussians, Canny edges and Hough line detection
  • A* search over corner candidates, with geometric pruning for A4 shape
  • Tested on 19 real photos: found a valid A4 shape in 18, with A*-h1 giving the best result in 14
  • Benchmarked against BFS — the faster A* heuristic ran about 26% quicker on average
My part: wrote a large share of the base code for the detection pipeline, and contributed my own photos to the test dataset.

Solo project · My first project · COMP1028 · C

A command-line tool written in C that scans text and CSV files to detect toxic and cyberbullying language, then reports detailed statistics.

  • Multi-file analysis, colour-coded terminal output, and report export to TXT or CSV
